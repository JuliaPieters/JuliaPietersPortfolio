Veilig delen website voor Nedbase

Dit project heb ik gedaan tijdens mijn meewerkstage bij Nedbase Digital Agency.

Context

De traffic medewerkers van Nedbase gebruiken een website met de naam ots.nedbase.nl. Op deze website kunnen medewerkers een bericht, wachtwoord, URL etc. invullen die daarna wordt gegenereerd tot een willekeurige URL. Deze URL sturen de traffic medewerkers door naar klanten van Nedbase. De klanten kunnen de URL openen waarna zij het desbetreffende bericht, wachtwoord of URL zien.

Een gegenereerde URL is maximaal 7 dagen geldig en wordt na het openen meteen verwijderd. Op deze manier kunnen gegevens op een veilige manier heen en weer worden gestuurd.

Probleemstelling

De trafficmedewerkers stuiten echter op verschillende problemen. De website komt onbetrouwbaar over omdat deze niet in de Nedbase huisstijl is vormgegeven. Daarnaast is het voor klanten onduidelijk hoe lang een URL geldig blijft en dat de URL na opening wordt verwijderd. Dit is onhandig als een klant met verlof is of ziek is en de URL dan vervalt. Bovendien bevat de website te veel overbodige informatie. Het was aan mij om de website te voorzien van een betere layout en functionaliteit.

Proces

Na brainstormen en gesprekken met stakeholders kwam ik op het idee om de geldigheid van de URL te veranderen naar 14 dagen in plaats van 7 dagen, om te voorkomen dat klanten de URL te laat openen. Ook koos ik ervoor om het kleurencontrast te verbeteren en de Nedbase huisstijl toe te passen. Ik maakte een definitief Figma-concept als eindontwerp.

Realisatie

Voor de realisatie heb ik de website uitgewerkt in het Angular framework. Hieronder zie je links de oude website en rechts de nieuwe website die ik heb ontworpen en gerealiseerd.

Mijn ontwikkeling

Bij dit project heb ik geleerd hoe ik gesprekken met stakeholders kan voeren, de uitkomsten van die gesprekken kan vertalen naar ontwerpen, en uiteindelijk een ontwerp kan realiseren dat in gebruik wordt genomen bij Nedbase. Ook voerde ik behavior tests en code reviews uit om te reflecteren op mijn geschreven code.
